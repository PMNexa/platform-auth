# platform-auth

Authentication module of the PMNexa platform: users, login/signup, JWT access tokens with rotating refresh tokens (Django + DRF backend), plus a frontend package with the login/signup screens and the session store. Used by [GoalNexa](https://github.com/PMNexa/GoalNexa). See `AGENTS.md` for how it works and how a host app imports it.
